# 💇 Salon Appointment System

A modern frontend web application for managing salon appointments.  
The system allows customers to explore salon services, book appointments, manage their bookings, while staff and admin roles handle scheduling and special cases.

Built with a scalable **Feature-Based React Architecture** to support teamwork and future expansion.

---

## 🚀 Features

### 👤 Customer Features
- User registration and login
- Browse salon services
- Select preferred stylist
- Book appointments
- Choose date and available time slots
- View upcoming appointments
- Reschedule appointments
- Cancel appointments
- Manage profile information

---

### ✂️ Staff Features
- Staff dashboard
- View assigned appointments
- Manage personal availability
- Block unavailable times
- Request leave

---

### 🛠️ Admin Features
- Admin dashboard
- Manage appointments
- Handle staff requests
- Assign/reassign stylists
- Manage customers

---

### 🌐 Public Features
- Modern landing page
- Salon introduction
- Services showcase
- Gallery section
- Customer testimonials
- Location and contact information

---

# 🏗️ Project Architecture

The project follows a **Feature-Based Architecture**.
